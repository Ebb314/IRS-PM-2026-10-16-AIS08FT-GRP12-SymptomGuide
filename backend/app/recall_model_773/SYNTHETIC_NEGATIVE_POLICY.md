# 阴性证据训练政策与三态版本变更

日期：2026-10-15。

原数据集仅给出 0/1 特征。原 773 类 v1 将 1 视为已知存在、0 视为未知，不接收明确否认。这一版本的训练结果与交接包保留。

用户本次明确接受将 0 当作模拟阴性用于实验，并要求以阳性训练对为主、只使用少量模拟阴性，再考虑配对排序。于是新增 773 类三态 v2，实验假设标记为 `synthetic_zero_assumption`。

公开[数据卡](https://data.mendeley.com/datasets/2cxccsxydc/1)说明数据是人工生成，但尚未核实所有 0 的明确否认语义。因此该政策不是声称原始 0 已得到临床标注核验，而是记录经用户确认的研究假设。

## 输入语义

| 状态 | 存在通道 | 否认通道 | 用途 |
| --- | ---: | ---: | --- |
| 阳性 | 1 | 0 | 患者明确有该症状 |
| 阴性 | 0 | 1 | 患者明确否认该症状 |
| 未知 | 0 | 0 | 未询问、不确定或未提供 |

真实接口输入可以表达患者的明确否认；训练中的否认监督则来自模拟假设，二者的数据可信度不能混淆。两个通道同时为 1 是无效状态，会报错。

## 最小阴性暴露

- 原始记录和症状组合分组切分不变。
- 阳性输入随机遮蔽，未揭示的症状变为未知。
- 75% 训练视图没有阴性证据；25% 视图揭示 1–3 个原 0 位置。
- 不把所有 0 自动作为输入否认，也不把原 1 翻转成否认。
- 配对辅助仅作用于约 25% 视图，每例一个对照疾病，权重 0.05。所有视图仍以正确疾病的 Cross-Entropy 为主监督。

## 对照与限制

比较三态 CE 与三态 CE + 少量 pairwise，按验证集决定模型。测试同一批病例、相同阳性输入，比较加入或擦除模拟阴性后的指标。模型可接受纯阴性输入，但此类场景未被训练视图充分覆盖；全未知输入会请求已知证据，不返回排名。

测试仍只覆盖 617/773 类，假设本身也需要将来用真实否认记录验证。模拟阴性实验的准确率、变化比例和配对效果不能作为真实医疗有效性的证明。若未来获得可靠阴性标签，应替换此模拟策略并独立评估。
