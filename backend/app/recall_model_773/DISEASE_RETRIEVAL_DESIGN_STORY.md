# 疾病召回模型：从三态证据到配对训练的实验与选择

## 可直接用于报告的段落

我们将疾病召回建模为患者证据与疾病表示之间的匹配任务，采用 Two-Tower 神经网络对候选疾病进行排序。首先建立基于阳性症状的模型，随后发现交互问诊必须区分“明确存在”“明确不存在”和“未知”。因此，我们保留原来的 413 疾病 baseline，另外基于 DDXPlus 合成患者数据建立了支持 49 种疾病的三态版本，用两个输入通道分别编码 95 个二元症状的存在和否认状态，未观察的症状保持未知。阴性答案由模拟患者的默认状态生成，不将原始疾病—症状数据中语义未确认的 0 直接解释为患者否认。

在训练目标上，我们先使用全量 Softmax Cross-Entropy，再引入推荐系统常见的正负配对排序作为对照。Cross-Entropy 并非没有困难负例：它对全部 49 个疾病同时计算分数，错误疾病得到的相对分数越高，对损失产生的梯度越大，因此高分错误候选已经参与训练。显式困难负例采样在当前小规模疾病空间内，并不是覆盖这些候选的必要条件。我们仍然实现了纯配对损失和 Cross-Entropy 加配对损失两个版本，每个患者输入配合四个高分负候选和四个随机负候选，同时避免把完整鉴别诊断列表中的其他合理疾病用于配对项的负例。

在相同数据切分、症状揭示方式、模型宽度和训练预算下，原 Cross-Entropy、纯配对、混合目标的验证集 MRR 分别为 0.9051、0.8720 和 0.9046。我们根据验证集结果保留 Cross-Entropy；在最多三个阳性症状和五个随机阴性答案的测试设置下，三者 Hits@1 分别为 83.07%、78.11% 和 83.05%。这一结果说明，本轮配对训练未带来收益，不能认为增加排序损失一定改善召回。我们因此选择当前验证表现更好的方案，并保留配对实验作为可复现的设计对照。

目前三态接口已能正确区分否认与未知，模型也确实会利用阴性输入调整匹配分数，但随机阴性答案尚未提升总体召回。因此，我们将“支持阴性证据”与“阴性证据提高准确率”作为两个独立结论。后续重点是改善阴性证据的训练与评估方式，以及处理少量已知症状下的多疾病合理性，而不是仅增加模型复杂度。

## 答辩时解释：为什么 Cross-Entropy 也在处理困难负例？

对一个患者，设疾病 j 的匹配分数为 z_j，训练时的 Softmax 权重为 p_j，记录疾病为 y。普通单标签 Cross-Entropy 为：

\[
p_j=\frac{e^{z_j}}{\sum_k e^{z_k}},\qquad L=-\log p_y
\]

对一个非记录疾病 j，损失相对于其分数的导数为：

\[
\frac{\partial L}{\partial z_j}=p_j,\qquad j\neq y
\]

因此，某个错误疾病如果得到很高的 Softmax 权重，就会对梯度产生较大贡献；优化过程会推动降低其相对分数。一个已被模型判得很低的容易负例，其贡献则较小。这是全量 Cross-Entropy 已经关注高分错误候选的数学原因，不等同于显式执行了 hard-negative mining。Softmax 权重在这里用于训练，也不能直接称为已校准的患病概率。

例如，假设真实标签为疾病 A，而模型暂时给 A、B、C 的权重分别为 0.4、0.5、0.1，那么错误候选 B 对分数的梯度是 0.5，C 是 0.1。训练会对更容易混淆的 B 施加更大的分数调整信号。这只是说明损失机制的假设例子，不是当前模型的实际病例或临床概率。

## 必须区分的三个概念

| 概念 | 在项目中的含义 |
| --- | --- |
| 阴性症状 | 患者明确否认某个症状，属于输入证据 |
| 困难负疾病候选 | 与患者输入相似、当前得分较高，但被训练规则选作对照的疾病 |
| 假负疾病候选 | 被标作负例，却可能是临床上仍合理的候选疾病 |

Cross-Entropy 在小规模类别空间内可以比较全部疾病，但仍然面临假负例问题。当前单一 PATHOLOGY 标签目标会与所有其他疾病竞争；在信息不完整、疾病症状重叠或存在多个合理诊断时，这个目标可能过于严格。因此，“全量计算覆盖困难候选”不能被表述为“Cross-Entropy 已经解决医疗负例问题”。

配对项排除鉴别列表中的候选，减少了一类假负例风险；但完整病例的鉴别列表不一定包含仅观察少量症状时的全部合理候选。混合模型中的 CE 项也仍然采用单标签监督，不能声称整个模型已经消除假负例。

纯配对表现较低的一种可能解释是：保护鉴别列表中的候选后，模型对正确疾病与这些合理候选之间的顺序约束较弱。不过，这只是结合目标设计提出的解释，本轮实验尚未通过单独消融确认原因。

## 如何准确讲述实验价值

推荐表达：

> 我们不仅建立了疾病召回 baseline，还通过三态证据建模和正负配对实验检验了设计选择。结果表明，当前疾病规模下，全量 Cross-Entropy 已经覆盖高分错误候选；显式配对排序在本轮实验中没有改善召回，因此我们依据验证集结果保留 baseline，并明确记录医疗假负例和阴性证据利用的后续问题。

避免表达：

- “Cross-Entropy 没有困难负例问题。”
- “困难负例采样没有作用。”
- “阴性症状能自动排除疾病。”
- “三态模型已经提高诊断准确率。”
- “模型已经融合 KG 进行医学推理。”当前 KG 仅附带疾病名称精确匹配的节点候选，没有参与训练或排序。

## 实验边界

- 三态与配对实验支持 49 种 DDXPlus 疾病，与原 413 疾病模型是不同范围，不能直接比较准确率。
- 数据是合成患者；严格清洗后测试覆盖 48 种疾病，喉痉挛无剩余独立测试病例。
- 完整证据已去重并跨集合排重，但投影到 95 个二元症状后，大量测试输入仍在此前集合出现。指标不能作为新症状组合泛化或现实临床准确率的证明。
- 每疾病抽样上限改变了类别分布；模型不输出经过校准的真实患病概率。
- 测试集此前已查看，本轮是固定方案的后续对照，不是新的盲测。混合目标与 CE 的差异很小，未进行统计显著性检验，不能据此宣称稳定优势。
- 原 413 疾病 baseline 也已去重和按完整症状向量分组，但增强数据来源不可得，无法排除近似重复或模板来源泄漏。

## 后续扩展：原数据集全部 773 类

在完成 49 类三态与配对实验后，我们进一步按全量覆盖目标训练原数据集的全部 773 个疾病标签和 377 个症状。去重后的 189,647 条记录全部保留，不再设置最小样本数门槛。按完整症状组合隔离集合，并保证每个标签至少有一条训练记录；使用平方根反频率类别权重与阳性症状遮蔽，按验证集 macro MRR 选择权重。

训练覆盖 773 类，验证覆盖 628 类，测试覆盖 617 类。在最多三个阳性症状输入下，全量模型 Hits@1 为 55.72%、Hits@5 为 89.92%、Hits@10 为 97.15%，MRR 为 0.7031；同切分的画像基线 Hits@5 为 82.84%。全部 773 类仍参与候选排序，但这些指标仅验证有独立测试记录的类别。108 类只在训练集出现，46 类只有一条不同记录，因此扩大输出范围并不等于证明极少样本疾病的可靠识别。

我们同时建立原数据集、DDXPlus 和共享 KG 的统一实体目录，保留原始标签和来源，并通过规范名、EXACT 同义词和分组成员编码链接 MONDO/HPO。原 773 标签有 434 个解析到唯一 MONDO 概念，425 个有 KG 候选链接（含非等价的分组成员链接），377 症状有 309 个 HPO/KG 候选。歧义、冲突和多对一映射仍标记待复核。

这个扩展没有将两个数据集的病例直接混合：原始 0 的否定语义未确认，所以全量模型仍只支持存在与未知，明确否认输入会被拒绝。实体目录统一解决协作中的编码与来源追踪问题，尚不表示完整医学映射或 KG 已参与模型训练。

## 三态 v2：经确认的模拟假设与少量阴性训练

2026-10-15，用户明确接受把原始 0 用作模拟阴性，并要求以阳性训练对为主。因此新增 754 维三态输入，区别于上节保留的 377 维阳性版本。原始 0 的临床意义仍未得到核验，这是一项明确记录的研究假设，不能改写成已经获得真实患者否认标签。

每轮约 75% 的证据视图只含阳性，25% 加入 1–3 个模拟阴性。正确患者—疾病标签是主监督；辅助配对只为约 25% 视图选择一个对照疾病，权重 0.05，并保守排除同 KG 分组成员候选。初始化复制旧阳性模型，新增阴性列从零开始，保持无阴性输入时的初始评分一致。

三态 CE 与 CE + 少量 pairwise 各继续训练十轮，验证集分别得到 0.74464 与 0.74403 的双视图 macro MRR 选择指标，保留 CE。最多三个阳性症状时，CE 在没有阴性与加入三个模拟阴性的平均 Hits@5 分别为 89.83% 和 90.02%，MRR 为 0.70385 和 0.70514；macro MRR 则从 0.75772 降至 0.75288。微平均与疾病等权指标存在取舍，不能把小幅总体变化宣称为稳定的医疗准确率收益。

同模型固定输入的消融中，约 15.51% 病例改变了 Top-1，说明阴性通道确实被模型使用。当前接口已支持阳性、阴性、未知，矛盾状态报错，全未知请求更多证据。它完成了输入能力扩展，但阴性监督质量与真实场景效果仍是需要独立验证的问题。
